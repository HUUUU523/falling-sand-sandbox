# Falling Sand Sandbox — 终端掉落沙盒

一个在 Windows 终端里运行的物理沙盒游戏，纯 C++17 实现，零第三方依赖。用键盘控制画笔，实时绘制沙子、水、火、熔岩等多种粒子，观察它们在重力、流动、燃烧、生长等物理规则下的演化。

![C++17](https://img.shields.io/badge/C++-17-blue) ![Windows](https://img.shields.io/badge/Windows-Terminal-green)

## 功能特性

- **9 种粒子**：沙子、水、石头、火、油、蒸汽、植物、熔岩、烟
- **真实物理**：重力下落、液体水平流动、密度分层（沙子沉水、水沉油）、火焰燃烧与熄灭、熔岩遇水固化、植物遇水生长、蒸汽上升凝结
- **实时交互**：方向键移动画笔，空格绘制，数字键切换粒子
- **彩色渲染**：ANSI 256 色终端渲染，火焰颜色随寿命动态变化
- **性能优化**：行内颜色合并输出，80×30 网格稳定 60 FPS

## 编译与运行

### 环境要求
- Windows 10/11（需要终端支持 ANSI 转义码）
- MinGW g++ 或 MSVC（本项目以 g++ 为例）

### 编译
```bat
cd falling_sand
build.bat
```
或手动编译：
```bat
g++ -std=c++17 -O2 -o falling_sand.exe src\main.cpp src\simulation.cpp src\renderer.cpp
```

### 运行
```bat
falling_sand.exe
```

> 建议在 Windows Terminal 或新的 cmd 窗口中运行，以获得最佳 ANSI 彩色效果。

## 操作说明

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` | 移动画笔 |
| `空格` | 在画笔位置绘制当前粒子 |
| `1` ~ `8` | 选择粒子（沙子/水/石头/火/油/蒸汽/植物/熔岩） |
| `0` | 擦除模式 |
| `[` / `]` | 减小 / 增大画笔半径 |
| `P` | 暂停 / 继续模拟 |
| `C` | 清空画布 |
| `R` | 重置为默认场景 |
| `ESC` | 退出 |

## 粒子行为一览

| 粒子 | 行为 |
|------|------|
| **沙子** | 受重力下落，堆积成斜面，可沉入水和油 |
| **水** | 下落并水平流动，比油重（沉到油下），可浇灭火 |
| **石头** | 静止不动，作为容器和屏障 |
| **火** | 向上飘动，点燃油和植物，遇水熄灭，寿命有限 |
| **油** | 粘稠液体，浮在水面上，高度易燃 |
| **蒸汽** | 上升，靠近顶部时凝结成水 |
| **植物** | 静止，周围有水时缓慢生长扩散，可燃 |
| **熔岩** | 缓慢下落，点燃一切可燃物，遇水变成石头并产生蒸汽 |
| **烟** | 火焰熄灭后产生，上升消散 |

## 有趣的实验

1. **火山喷发**：在底部画一堆熔岩，上面盖一层石头，看熔岩如何突破并点燃一切
2. **水火不容**：画一条水渠，然后在旁边点火，观察蒸汽的产生
3. **生态瓶**：底部铺石头，加水，种植物，观察植物如何在水中生长蔓延
4. **油画燃烧**：画一池油，扔一个火星进去，看整个油池如何被点燃
5. **沙漏**：用石头搭一个漏斗，装满沙子，看沙子如何流动堆积

## 技术要点

- **更新顺序**：从底部向上逐行遍历，每行交替左右方向，避免粒子在一帧内连续移动多格，同时消除方向性偏差
- **密度交换**：粒子移动时若目标格密度更小则交换位置，实现沙子沉水、水沉油等分层效果
- **ANSI 渲染优化**：逐行扫描合并连续相同颜色的格子，只在颜色变化时输出转义码，大幅减少终端输出量
- **Windows 控制台**：通过 `ENABLE_VIRTUAL_TERMINAL_PROCESSING` 启用 ANSI 支持，设置 UTF-8 代码页确保中文显示
